# Домашнее задание «Анализ обращений клиентов»

Задание

В этом задании вы проанализируете реальные обращения клиентов в службу поддержки, используя библиотеку Pandas. Вам предстоит отфильтровать данные по заданным условиям, создать новые вычисляемые столбцы, рассчитать метрики удовлетворенности пользователей и сформировать итоговый аналитический вывод для руководителя.
Поиск ответов в сырых таблицах — базовая задача любого дата-специалиста. В реальной работе вы будете регулярно разбирать похожие выгрузки из CRM или логов техподдержки. Главное здесь — не просто посчитать метрики в Pandas, а увидеть за цифрами реальные проблемы пользователей и превратить статистику в понятные решения для бизнеса.

Выполнив это задание, вы:

Освоите фильтрацию DataFrame по условиям;
Научитесь создавать вычисляемые столбцы;
Освоите подсчёт средних значений и сортировку;
Научитесь формулировать аналитические выводы на основе данных.
Время на выполнение задания: 180 минут.

Описание задания
Вы — аналитик в компании, которая продаёт электронику и программное обеспечение. Компания собрала обращения клиентов в службу поддержки и хочет проанализировать качество обслуживания.
Вы будете работать с реальным датасетом «Customer Support Ticket Dataset» с Kaggle.
Источник данных: Customer Support Ticket Dataset

Исходные данные
Загрузите датасет с Kaggle. Датасет в шаблоне к данному заданию.

Задание 1. Первичный осмотр данных
Прежде чем анализировать обращения, нужно понять структуру данных.

Задачи:

Выведите размер таблицы (атрибут .shape);
Выведите первые 5 строк с помощью .head();
Выведите общую информацию с помощью .info();
Выведите статистику числовых столбцов с помощью .describe();
Посмотрите на уникальные значения в столбцах Ticket Priority и Ticket Channel (используйте .value_counts()).
Вопрос:
Сколько всего обращений в наборе данных? Какие приоритеты существуют? Какие каналы связи используются?
Задание 2. Фильтрация данных
Руководитель хочет разобраться в конкретных проблемах. Он просит отобрать обращения по разным критериям.
Задачи:
2.1. Проблемные обращения
· Отберите все обращения с оценкой удовлетворённости ниже 3.0 (столбец Customer Satisfaction Rating).
· Сохраните результат в переменную df_low_satisfaction.
· Выведите количество таких обращений.
2.2. Критические обращения по конкретных каналах
· Отберите обращения с приоритетом «Critical», которые поступили через каналы «Phone» или «Chat».
· Сохраните результат в переменную df_critical_phone_chat.
· Выведите результат.
2.3. Обращения по конкретным продуктам
· Отберите обращения по продуктам «GoPro Hero» или «Dell XPS», где приоритет «High» или «Critical».
· Сохраните в переменную df_tech_urgent.
· Выведите только столбцы: Ticket ID, Product Purchased, Ticket Priority, Ticket Channel, Customer Satisfaction Rating.
· Отсортируйте по Customer Satisfaction Rating по возрастанию.

Задание 3. Вычисляемые столбцы
Для оценки качества работы службы поддержки нужны дополнительные показатели.
Задачи:
3.1. Признак низкой удовлетворённости
Создайте новый столбец is_low_satisfaction, который равен True, если Customer Satisfaction Rating меньше 3.0, и False в противном случае.
3.2. Категория возраста клиента
Создайте столбец age_group по правилу:
· Если Customer Age < 30 → значение «Молодой»;
· Если Customer Age < 50 → значение «Средний»;
· Если Customer Age >= 50 → значение «Старший».

Задание 4. Агрегация и сортировка
Для отчёта руководству нужны конкретные цифры.
Задачи:
4.1. Средние показатели
Рассчитайте и выведите:
· Среднюю оценку удовлетворённости по всем данным;
· Среднюю оценку удовлетворённости для обращений с приоритетом «Critical»;
· Среднюю оценку удовлетворённости для обращений с приоритетом «Low»;
· Средний возраст клиента по всем данным.
4.2. Сравнение по каналам
Рассчитайте среднюю оценку удовлетворённости отдельно для каждого канала:
· «Email», «Phone», «Social media», «Chat» Выведите результаты в читаемом виде.
4.3. Топ самых проблемных продуктов
С помощью .value_counts() определите топ-5 продуктов (Product Purchased), на которые поступило больше всего обращений. Выведите результат.
