Описание задания
Вы — аналитик в сети кофеен. Компания ведёт учёт заказов в единой системе, но данные поступают из нескольких источников: кассовые терминалы, мобильное приложение, агрегаторы доставки. Из-за этого в данных регулярно встречаются ошибки: неверные типы столбцов, пропуски, дубликаты и выбросы.
